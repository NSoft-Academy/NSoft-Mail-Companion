# Design system

Operational panel uses a dark technology palette, blue/mint accents, fluid headings, rounded panels, visible focus rings and semantic form labels. Desktop has a persistent sidebar; mobile has a collapsible navigation panel with Escape support. States include connecting, unauthenticated, MFA setup, empty, success and error. Data comes from Express; no fabricated dashboards or usage charts.

Validate keyboard operation, automated axe checks and horizontal overflow at 320, 390, 768, 1024, 1440 and 1920px. Respect reduced-motion preference. Private operational pages use noindex; this is not the public NSoft marketing website.
