# Security policy

This initial implementation is for controlled pilots. Do not report vulnerabilities with credentials, message contents or production mail logs in public issues.

Use GitHub private vulnerability reporting for NSoft-Academy/NSoft-Mail-Companion when enabled. If unavailable, request a private reporting channel from the repository owner without publishing exploit details. The repository owner must enable private reporting before announcing a general release.

Report the affected revision, component, reproduction using synthetic data, impact and proposed mitigation. Maintainers should acknowledge reports, coordinate fixes and advisories, and disclose after a patch is available. Never test against third-party domains or mailboxes without permission.
